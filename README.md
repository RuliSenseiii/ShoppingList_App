# 🛒 Lista de la compra

App Android para planificar la compra, tachar productos mientras compras y llevar el recuento de lo que tienes en casa.

Proyecto personal mediante vibe coding con 'Claude Code' para ayudar con las tareas del hogar, código abierto.

📖 **[Guía de uso para usuarios](GUIA.md)** — se actualiza con cada versión.

Versión actual: **V0.8**. La app incluye un tutorial guiado (botón **?** en la pantalla principal).
